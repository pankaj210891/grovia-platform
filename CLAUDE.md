# Grovia AI Context

Grovia is a modern marketplace-ready ecommerce platform built using NextJS, TypeScript, and Turborepo.

The platform is being developed using GSD-style AI-assisted engineering workflows.

# Development Workflow

All development follows:

1. architecture planning
2. implementation planning
3. execution
4. verification
5. commit

Never:

- implement giant features at once
- bypass verification
- introduce hardcoded assumptions
- tightly couple packages

Always:

- maintain package boundaries
- keep systems reusable
- optimize developer experience
- prioritize scalability
